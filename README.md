# Bee3

Криптографическая библиотека — преемник Bee2 (НИИ ППМИ БГУ).

Bee3 не является «версией 3» Bee2: Bee2 и Bee3 не образуют версионной
линейки. Bee3 наследует алгоритмы и проверенные наработки Bee2 и
расходится с ним в требованиях к безопасности, сборке и API.

## Состояние

Каркас, инфраструктура сборки и два примитива. Остальное не перенесено.

```
include/bee3/            публичные заголовки
  defs.h                 маркировка API, контроль конфигурации сборки
  core/                  очистка памяти, работа с секретами
  crypto/belt.h          блочный шифр belt
  crypto/bash.h          sponge-функция bash и хэширование
  crypto/legacy/         устаревшие примитивы (собираются только по запросу)
src/crypto/belt/         табличное исполнение belt
src/crypto/bash/         bash-f и bash-hash
cmake/                   строгие наборы флагов
tools/                   проверки, запускаемые в CI
docs/LEGACY.md           что исключено и почему
docs/notes/              разборы примитивов
```

## Сборка

```sh
cmake --preset rel
cmake --build --preset rel
ctest --preset rel
```

Требуется CMake 3.25+, компилятор с поддержкой C23.

## Правила сборки

| Правило | Механизм |
|---|---|
| Расширения компилятора — ошибка | `-pedantic-errors`, `CMAKE_C_EXTENSIONS OFF`, `/permissive-` |
| Предупреждения — ошибки | `-Wall -Wextra -Werror` плюс ~35 специализированных флагов |
| Устаревшее API не компилируется | `-Werror=deprecated-declarations` |
| Устаревшие примитивы вынесены | `BEE3_ENABLE_LEGACY` (по умолчанию `OFF`), список в `docs/LEGACY.md` |
| Очистка секретов реальна | `tools/check_nobuiltin.sh` проверяет машинный код |
| Разделение legacy герметично | `tools/check_legacy_leaks.py` обходит дерево `#include` |
| Все меры защиты активны | стек-протектор, `_FORTIFY_SOURCE`, RELRO, BIND_NOW, NX-стек, скрытая видимость символов |

Проверки конфигурации:

```sh
python3 tools/check_legacy_leaks.py
bash    tools/check_nobuiltin.sh
```

## Что реализовано

| Примитив | Стандарт | Проверка |
|---|---|---|
| `belt` — блочный шифр, 128/192/256 бит ключа | СТБ 34.101.31-2020 | вектор приложения А.1, побайтово с эталоном |
| `bash-f` — sponge-функция, состояние 1536 бит | СТБ 34.101.77-2020 | таблицы А.1 и А.2 |
| `bash-hash` — хэширование, 256/384/512 бит | СТБ 34.101.77-2020 | таблица А.3 (11 значений) + 579 пар с эталоном Bee2 |

Константно-временность: `bash-f` константно-временна по построению — в `bash-s`
нет ни одного обращения к памяти по индексу, зависящему от данных. У `belt`
табличная подстановка, константно-временная версия исключена из сборки,
см. `docs/notes/001-belt-h.md`.

## Документация

Документы проекта оформлены по ГОСТ 7.32-2017: реферат, перечень сокращений,
введение, основная часть, заключение, список использованных источников.
Библиографические записи составлены по ГОСТ Р 7.0.5-2008 и
ГОСТ Р 7.0.100-2018.

- `docs/LEGACY.md` — материал, исключённый из сборки по умолчанию,
  с основаниями и заменами;
- `docs/notes/001-belt-h.md` — подстановка H шифра belt и вопрос
  константно-временности;
- `docs/notes/002-bash.md` — sponge-функция bash, константно-временность по
  построению и расхождение в описании дополнения сообщения.

## Ограничения

- C как основной язык. C++23 рассматривается только для типизированного
  слоя поверх.
- Остальные примитивы и форматы не перенесены, библиотека непригодна для
  применения. Это сделано намеренно: публиковать криптографию под именем Bee3
  до переноса и проверки механизмов защиты было бы хуже, чем не публиковать
  её вовсе.
- Константно-временная реализация `belt` исключена из сборки: расхождение с
  эталоном не локализовано, см. `docs/notes/001-belt-h.md`.
- Найдено одно расхождение в тексте СТБ 34.101.77-2020 (описание дополнения
  сообщения), см. `docs/notes/002-bash.md`, п. 2.5.
